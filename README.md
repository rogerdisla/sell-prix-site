# SELL PRIX LLC Website

Official informational website for SELL PRIX LLC: https://sellprixllc.com/

Built as a lightweight static website and hosted using GitHub Pages.

## Pages
- `index.html`: company homepage and La Ficha introduction
- `la-ficha.html`: dedicated La Ficha product page with features, screenshots, and FAQs
- `support.html`: product support and detailed La Ficha FAQs
- `privacy.html`: website privacy policy (not an app-specific privacy disclosure)
- `terms.html`: website terms
- `styles.css`: responsive design and interactive component styles
- `script.js`: accessible mobile navigation
- `favicon.svg`: branded browser tab icon
- `robots.txt` and `sitemap.xml`: basic search engine discovery
- `assets/la-ficha-*.jpeg`: existing approved La Ficha screenshots; preserve the source files

## Approved screenshot preservation

## Release readiness
La Ficha is marked **In development**. The site does not claim an App Store or Google Play
release. Before publishing the native app, finalize app-specific privacy disclosures and
add verified store URLs only after the corresponding listings are live.

## Editing
Make changes in a feature branch, check responsive/mobile layouts and accessibility,
and merge to `main` after review. Updating `main` deploys via GitHub Pages.
